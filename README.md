# ai-agriculture-chatbot.
Developed a conversational AI system for agricultural recommendations using Gemini API and LangChain
Implemented context-aware responses and backend APIs using FastAPI
## Technologies Used
- Python
- FastAPI
- LangChain
- Google Gemini API
- Prompt Engineering

## Key Functionality
- Analyzes soil parameters (pH, moisture, nutrients, etc.)
- Provides simplified recommendations for farmers
- Maintains conversation context for better interaction
- Offers plant disease diagnosis and treatment advice
